# Data Science with Python

A practical collection of Python-based data analysis and preprocessing work covering
numerical computing, data manipulation, visualization, data cleaning, and feature engineering.

## Overview

This repository contains hands-on work developed using Python and popular data science
libraries. It demonstrates the process of working with datasets, analyzing data,
creating visualizations, cleaning data, and preparing features for further analysis
and machine learning applications.

## Areas Covered

### NumPy Fundamentals
- Array creation and attributes
- Indexing and slicing
- Broadcasting
- Arithmetic and statistical operations
- Concatenation and reshaping
- Sorting and splitting arrays

### Pandas Data Analysis
- Creating DataFrames
- Loading datasets
- Inspecting rows and columns
- Understanding DataFrame properties
- Working with structured data

### Data Manipulation
- Selecting data
- Filtering records
- Sorting data
- Updating values
- Creating new columns

### Data Visualization
- Line charts
- Bar charts
- Pie charts
- Histograms
- Scatter plots
- Count plots
- Box plots
- KDE plots

### Data Cleaning
- Detecting duplicate records
- Handling missing values
- Detecting outliers
- IQR-based outlier detection
- Data preprocessing using Pandas and Scikit-learn

### Feature Engineering
- Removing unnecessary features
- Numerical feature scaling
- Standardization
- Min-Max normalization
- Preparing categorical variables

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
